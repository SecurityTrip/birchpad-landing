---
title: Side panels
description: Document List, Function List, Document Map, Folder as Workspace, Project Panels, Clipboard History and the Character Panel.
---

Panels dock to the left, right or bottom of the documents. Several panels on one side become tabs. Open panels come back on the next start.

| Panel | Where | What it does |
|---|---|---|
| Document List | **View** | The open documents with their paths. Click to show one, middle-click to close it, click a heading to sort. |
| Function List | **View** | The document's classes, functions, methods and sections as a tree, for 28 languages including Markdown headings. Follows edits, highlights the definition the caret is in, filters and sorts. |
| Document Map | **View** | The whole document in miniature in its syntax colors, the visible part framed. Click or drag to scroll. |
| Folder as Workspace | **File → Open Folder as Workspace…** | Folders as trees, kept current as files come and go. Double-click opens a file. Its menu copies paths, runs Find in Files in a folder, opens the file manager or a terminal. |
| Project 1–3 | **View → Project** | Projects of folders and files in Notepad++'s `.workspace` files, so a project opens in both editors. Saved as soon as they change. |
| Clipboard History | **Edit** | Texts copied in Birchpad and other programs, newest first. Double-click to paste. |
| Character Panel | **Edit** | The 256 values of the document's code page with their characters and HTML entities. Double-click to insert. |
| Search results | <kbd>F7</kbd> | See [Find and replace](/en/docs/search/#search-results-panel). |

A folder dropped on the window or given on the [command line](/en/docs/command-line/) opens as a workspace too.
