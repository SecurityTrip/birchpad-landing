Документы Markdown и PlantUML показывают рядом с текстом то, что из него получается, — как в IntelliJ IDEA. Предпросмотр обновляется по мере ввода.

## Три вида

Кнопки в правом верхнем углу документа и **Вид → Предпросмотр** переключают:

- **Только редактор** — один текст;
- **Редактор и просмотр** — текст слева, страница или диаграмма справа;
- **Только просмотр** — только результат.

Выбор запоминается.

## Markdown

Страница строится из документа Markdown: заголовки, списки, таблицы, код с подсветкой, цитаты. Ссылки открываются в браузере, а ссылки на файлы — в Birchpad. Картинки берутся только из файлов рядом с документом и никогда не скачиваются из интернета.

## PlantUML

Файлы `.puml` показываются диаграммой. Рисует её PlantUML:

- команда `plantuml`, если она есть в системе;
- или `plantuml.jar`, путь к которому записан в настройке [`preview.plantuml`](/docs/settings/#preview) — он запускается через `java -jar`.

Если PlantUML не найден, предпросмотр предлагает **Установить PlantUML**: Birchpad скачает PlantUML и Java для него (около 50 МБ) из своих релизов на GitHub, проверит их и сохранит в папке данных. Graphviz не нужен — диаграммы раскладываются без него. Скачивание выключается вместе с сетевыми функциями (`network.online-features = false`); тогда поставьте PlantUML сами.
