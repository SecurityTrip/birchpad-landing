Birchpad по умолчанию ничего не спрашивает при выходе и ничего не теряет. Следующий запуск открывает те же документы — файлы и безымянные «new 1» — с несохранёнными правками, курсорами, прокруткой, свёрнутыми блоками, закладками, языками и кодировками.

## Как это работает

Каждые несколько секунд (7 по умолчанию) и при выходе Birchpad записывает копии документов с несохранённым текстом и описание сессии. Падение программы или выключение компьютера теряет не больше последнего интервала. Файлы на диске не трогаются, пока вы их не сохраните.

| Ключ `settings.toml` | По умолчанию | Значение |
|---|---|---|
| `session.remember` | `true` | Открывать документы прошлого запуска. |
| `session.backup-unsaved` | `true` | Хранить несохранённое в резервных копиях; выход не спрашивает. Нужен `remember`. |
| `session.backup-interval-seconds` | `7` | Как часто делать копии, в секундах. |

Без резервных копий выход спрашивает про каждый изменённый документ («Сохранить», «Не сохранять», «Отмена»), а безымянные документы в сессию не попадают. Ключ `-nosession` в [командной строке](/docs/command-line/) не восстанавливает и не сохраняет сессию. Администратор может запретить копии политикой `BackupUnsaved` (см. [Для администраторов](/docs/admin/)).

Сессия хранится в папке данных (см. [Настройки](/docs/settings/#где-лежат-файлы)): `session.toml`, предыдущая — `session.toml.bak`, копии — в папке `backup`. Файлы доступны только вашей учётной записи.

## Файлы сессий

**Файл → Сохранить сессию…** записывает список открытых файлов с позициями, закладками, свёрнутыми блоками и языками (без несохранённого текста). **Файл → Загрузить сессию…** и ключ `-openSession` открывают такой файл рядом с уже открытым.

Они же читают `session.xml` Notepad++: файлы обоих видов, курсоры, закладки, свёрнутые блоки, язык, «только чтение» и несохранённый текст из резервных копий Notepad++.

## Файлы, изменённые другими программами

Birchpad следит за открытыми файлами (`files.change-detection`: `all`, `current` или `off`). Изменённый файл без своих правок перечитывается — молча или после вопроса (`files.reload-silently`), с курсорами, закладками и свёрнутыми блоками на прежних строках. Если правки есть или файл удалён, Birchpad спросит.

**Вид → Мониторинг (tail -f)** дочитывает только добавленное в конец файла — удобно для журналов.
