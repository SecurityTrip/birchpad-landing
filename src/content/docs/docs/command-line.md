---
title: Командная строка
description: Ключи командной строки Birchpad, совместимые с Notepad++, и запуск одного экземпляра.
---

```text
birchpad [-n<строка>] [-c<колонка>] [-p<позиция>] [-l<язык>] [-ro] [-multiInst]
         [-nosession] [-openSession] [--] [ФАЙЛ]...
```

| Ключ | Значение |
|---|---|
| `-n<строка>` | Перейти к строке (с 1). |
| `-c<колонка>` | Перейти к колонке (с 1). |
| `-p<позиция>` | Перейти к смещению в байтах (с 0); важнее `-n` и `-c`. |
| `-l<язык>` | Язык подсветки: `-lcpp`, `-lpython`, `-lnormal`. Принимаются имена Notepad++ и [идентификаторы Birchpad](/docs/languages/). |
| `-ro` | Открыть файлы только для чтения. |
| `-multiInst` | Запустить отдельный экземпляр вместо передачи файлов уже запущенному. |
| `-nosession` | Не восстанавливать и не сохранять [сессию](/docs/sessions/). |
| `-openSession` | Файлы — это сессии (Birchpad или `session.xml` Notepad++). |
| `-notabbar` | Скрыть панель вкладок. |
| `-alwaysOnTop` | Окно поверх всех окон. |
| `-systemtray` | Запустить свёрнутым. |
| `-x<пиксели>`, `-y<пиксели>` | Положение окна. |
| `-titleAdd="текст"` | Добавить текст к заголовку окна. |
| `-settingsDir="папка"` | Взять настройки из этой папки. |
| `-udl="имя"` | Подсветить файлы пользовательским языком. |
| `-r` | Открыть файлы по маске (`*.log`) и во вложенных папках. |
| `-monitor` | Открыть с мониторингом изменений (`tail -f`). |
| `-quickPrint` | Напечатать файлы на принтере по умолчанию. |
| `-loadingTime` | Показать время загрузки. |
| `-qt="текст"`, `-qf="файл"`, `-qSpeed1`…`3` | «Призрачный ввод»: напечатать текст в новом документе, как будто его набирают. |
| `-nopluginsupport` | Запустить без плагинов; то же — `-noPlugin`. |
| `-L<код>` | Интерфейс на этом языке в этот раз: `-Lde`, `-Lru`. |
| `-notepadStyleCmdline`, `-z` | Подменять Блокнот Windows: путь к Блокноту пропускается, остальное — одно имя файла с пробелами. |
| `--help` | Показать справку по ключам командной строки. |
| `--` | Всё дальше — имена файлов, даже если начинаются с `-`. |

Ключи не различают регистр. Папка вместо файла открывается как [рабочее пространство](/docs/panels/).

## Один экземпляр

Если Birchpad уже запущен, повторный запуск передаёт файлы ему — они открываются вкладками — и сразу завершается. `-multiInst` открывает отдельное окно, а ключ `instances.mode` в [настройках](/docs/settings/#instances) делает это поведением по умолчанию.

## Совместимость с Notepad++

Ключи Notepad++ работают так же, как в нём. `-pluginMessage=` передаётся плагинам. Те немногие ключи, что Birchpad пока не поддерживает (например, `-fullReadOnly`), принимаются и игнорируются. Неизвестный ключ даёт предупреждение, но не мешает запуску. Поэтому ассоциации файлов, ярлыки и скрипты, написанные для Notepad++, продолжают работать, если заменить в них путь к программе.

## Примеры

```text
birchpad -n120 -c5 src\main.rs
birchpad -lpython -ro script.txt
birchpad -openSession "%APPDATA%\Notepad++\session.xml"
```
