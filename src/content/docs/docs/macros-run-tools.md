## Макросы

- **Макросы → Начать запись** (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd>) записывает выполняемые команды и набранный текст; повторное нажатие останавливает запись.
- **Воспроизвести** (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>) повторяет последний записанный макрос.
- **Выполнить макрос несколько раз…** — заданное число раз или до конца файла (пока курсор не дойдёт до конца текста или очередной прогон ничего не изменит).
- **Сохранить записанный макрос…** сохраняет его под именем. Сохранённые макросы появляются в меню **Макросы**, им можно назначить сочетание клавиш в **Опции → Горячие клавиши…**.

Макросы хранятся в `macros.toml` рядом с настройками:

```toml
[[macro]]
name = "Взять слово в кавычки"
steps = [
    { command = "edit.type", args = { text = "\"" } },
    { command = "cursor.word-right" },
    { command = "edit.type", args = { text = "\"" } },
]
```

## Запуск

**Запуск → Запустить…** выполняет командную строку через оболочку системы или открывает веб-адрес в браузере. Переменные — как в Notepad++:

| Переменная | Значение |
|---|---|
| `$(FULL_CURRENT_PATH)` | Полный путь текущего файла. |
| `$(CURRENT_DIRECTORY)` | Его папка. |
| `$(FILE_NAME)` | Имя с расширением. |
| `$(NAME_PART)` | Имя без расширения. |
| `$(EXT_PART)` | Расширение. |
| `$(CURRENT_WORD)` | Выделенный текст или слово под курсором. |
| `$(CURRENT_LINE)`, `$(CURRENT_COLUMN)` | Номер строки и колонки курсора. |
| `$(CURRENT_LINESTR)` | Текст текущей строки. |
| `$(NPP_DIRECTORY)`, `$(NPP_FULL_FILE_PATH)` | Папка и путь программы Birchpad. |
| `$(SYS.<ИМЯ>)` | Переменная окружения, например `$(SYS.TEMP)`. |

**Сохранить…** запоминает команду под именем в `run.toml`, и она появляется в меню:

```toml
[[command]]
name = "Поиск в Википедии"
line = "https://ru.wikipedia.org/w/index.php?search=$(CURRENT_WORD)"
```

## Инструменты

- **MD5, SHA-1, SHA-256, SHA-512 → Сгенерировать для выделения в буфер обмена** — хэш выделенного текста.
- **… → Сгенерировать для файлов…** — хэши выбранных файлов в новом документе, в формате `sha256sum`.
- **Кодировать в Base64** и обратно, **Кодировать URL** и обратно, **ASCII в HEX** и обратно — для каждого выделения сразу, одним шагом отмены.

## Печать

**Файл → Печать…** (<kbd>Ctrl</kbd>+<kbd>P</kbd>) открывает документ в цветах темы с номерами строк в диалоге печати браузера — оттуда же можно сохранить PDF. **Файл → Экспорт в HTML…** сохраняет ту же страницу файлом.
