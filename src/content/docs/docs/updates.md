title: Обновления и сеть
description: Как Birchpad проверяет и устанавливает обновления, каналы stable, beta и nightly, подписанный манифест и полностью автономный режим.
---

Birchpad проверяет обновления вскоре после запуска, затем раз в сутки и по команде **? → Проверить обновления…**. Он запрашивает подписанный манифест у сервиса Birchpad и при сбое обращается к GitHub. По умолчанию проверка отправляет статистику установок. Отключите её в **Опции → Настройки… → Обновления** или задайте `updates.statistics = false`. См. [Конфиденциальность](/privacy/).

## Режимы

| `updates.mode` | Что происходит |
|---|---|
| `auto` (по умолчанию) | Новая версия скачивается в фоне и устанавливается при следующем запуске. |
| `notify` | Birchpad сообщает о новой версии, но ничего не скачивает. |
| `off` | Проверка и загрузка обновлений отключены. |

Автоматически обновляются копии, установленные через Windows EXE для текущего пользователя и macOS PKG. Для MSI, DMG и портативных сборок новую версию устанавливают вручную.

В окне с новостью об обновлении кнопка **Обновить** скачивает, проверяет и ставит новую версию и перезапускает Birchpad с вашими документами; ход загрузки виден прямо в окне, а у фоновой загрузки — в строке состояния. «Больше не показывать» выключает проверку обновлений. Прокси для обновлений задаётся в **? → Прокси для обновлений…** (`updates.proxy`); по умолчанию берётся `HTTPS_PROXY` или `ALL_PROXY`, на Windows — системный.

## Каналы

| `updates.channel` | Что приходит |
|---|---|
| `stable` (по умолчанию) | Релизы. |
| `beta` | Бета-версии, кандидаты в релиз и релизы. |
| `nightly` | Всё, включая ночные сборки ветки следующей версии, когда в ней есть изменения. |

## Безопасность

Birchpad читает манифест обновлений, подписанный ключом проекта (ed25519), и отвергает любой другой. Манифест защищён от отката на старую версию, «заморозки» и подмены. `updates.url` позволяет брать манифест с внутреннего зеркала — но он всё равно должен быть подписан.

Каждый релиз публикуется с контрольными суммами SHA-256, SBOM и подтверждением сборки GitHub — см. [Установка](/docs/install/).

## Для администраторов

Политики `UpdateMode`, `UpdateStatistics`, `UpdateChannel` и `UpdateUrl` задают то же самое так, что пользователь не может это изменить. MSI-версия сама не обновляется — её обновляет администратор. См. [Для администраторов](/docs/admin/).
