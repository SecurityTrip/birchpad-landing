Все файлы лежат на [странице релизов](https://github.com/SecurityTrip/Birchpad/releases/latest). Birchpad бесплатен и не требует регистрации.

## Windows

| Файл | Для кого |
|---|---|
| `birchpad-<версия>-windows-x64-setup.exe` | Большинство пользователей. Ставится в профиль пользователя без прав администратора и обновляется сам. |
| `birchpad-<версия>-windows-arm64-setup.exe` | То же для компьютеров на ARM (Snapdragon и др.). |
| `birchpad-<версия>-windows-x64.msi` | Администраторы: установка на всю машину в `Program Files\Birchpad`. Обновляет администратор. См. [Для администраторов](/docs/admin/). |
| `birchpad-<версия>-windows-x64.zip`, `…-arm64.zip` | Портативная версия: распакуйте и запускайте, хоть с флешки. |

:::caution[SmartScreen]
Сборки для Windows пока не подписаны сертификатом, поэтому при первом запуске SmartScreen спросит: нажмите **Подробнее → Выполнить в любом случае**. Подпись через SignPath подготовлена и включится, когда у проекта появится сертификат. Пока подлинность файла подтверждают контрольные суммы и подтверждение сборки (см. ниже).
:::

Удалить установленный Birchpad можно в **Параметры Windows → Приложения → Установленные приложения**. Портативную копию достаточно удалить вместе с папкой.

## macOS

`birchpad-<версия>-macos.zip` содержит `Birchpad.app` для macOS 10.15.7 и новее, для Apple silicon и Intel. Распакуйте архив и перенесите приложение в «Программы».

Приложение пока не нотаризовано: в первый раз откройте его через **Control-клик → Открыть** и подтвердите запуск.

## Linux

`birchpad-<версия>-linux-x64.zip` — портативная сборка для x64. Чтобы Birchpad появился в меню приложений:

1. Положите исполняемый файл `birchpad` в каталог из `PATH`, например `~/.local/bin`.
2. Скопируйте `io.github.securitytrip.birchpad.desktop` в `~/.local/share/applications/`.
3. Скопируйте `io.github.securitytrip.birchpad.png` в `~/.local/share/icons/hicolor/512x512/apps/`.

## Портативный режим

Если рядом с исполняемым файлом лежит файл `birchpad-portable.txt` (в ZIP-архивах для Windows и Linux он уже есть), Birchpad хранит настройки, сессию и резервные копии в папке `data` рядом с собой и ничего не пишет в профиль пользователя. Политики администратора компьютера при этом всё равно действуют.

## Проверка загрузки

Каждый релиз собирается на серверах GitHub из открытого кода. Проверить, что файл не подменён, можно двумя способами:

- по контрольным суммам из `birchpad-<версия>-SHA256SUMS.txt` в релизе;
- по подтверждению сборки GitHub (нужен [GitHub CLI](https://cli.github.com/)):

```sh
gh attestation verify birchpad-0.1.4-windows-x64-setup.exe --repo SecurityTrip/Birchpad
```

В каждом релизе также есть SBOM — список всех зависимостей в формате CycloneDX (`…-sbom.cdx.json`).

## Ночные сборки

Ночные сборки следующей версии публикуются как пре-релизы. Чтобы получать их как обновления, укажите в настройках `updates.channel = "nightly"` — см. [Обновления и сеть](/docs/updates/).
