Меню **Плагины** собирает встроенные аналоги популярных плагинов Notepad++, установленные плагины и ваши скрипты.

Плагины Notepad++ — это библиотеки DLL для Windows, и Birchpad их не загружает. Плагины Birchpad — компоненты WebAssembly: они работают на всех системах и запускаются в песочнице.

## Встроенные плагины

### JSON Viewer

**Форматировать JSON** раскладывает значения по строкам с отступами редактора, **Сжать JSON** убирает пробелы и переносы, **Проверить JSON** ищет ошибку. Всё работает с выделением или со всем документом. Числа и строки остаются как написаны. При ошибке курсор встаёт на место ошибки, а сообщение объясняет, что не так.

### XML Tools

**Форматировать XML**, **XML в одну строку** и **Проверить синтаксис XML** — так же, как для JSON.

### Hex Editor

**Показать в шестнадцатеричном виде** открывает байты документа в его кодировке строками по 16 в новом документе. Отредактируйте их и выберите **Применить шестнадцатеричные данные к документу** — байты вернутся в исходный документ одним шагом отмены.

### Сравнение

**Сравнение** сравнивает активный документ с документом другого вида или с предыдущей вкладкой и ставит их рядом. Добавленные, удалённые и изменённые строки подсвечиваются целиком; **Следующее различие** и **Предыдущее различие** переходят между ними, **Очистить результаты** снимает подсветку. Можно игнорировать пробелы и регистр. Цвета задаются в теме: `compare-added`, `compare-removed`, `compare-changed`.

### Проверка орфографии

Работает как DSpellCheck в Notepad++:

- **Проверять орфографию автоматически** подчёркивает слова с ошибками; в коде — только в комментариях и строках;
- **Следующая ошибка** и **Предыдущая ошибка** переходят между ними;
- **Варианты исправления** показываются в списке автодополнения;
- **Добавить слово в словарь** и **Язык словаря**.

Словари — файлы Hunspell `.aff` и `.dic` из папки `dictionaries` рядом с настройками (**Открыть папку словарей**) или системные. В комплекте с Birchpad словарей нет: русский и английский словари Hunspell можно взять, например, из LibreOffice или из [репозитория словарей LibreOffice](https://github.com/LibreOffice/dictionaries).

## Установка плагинов

**Плагины → Управление плагинами…** показывает установленные плагины с версией, описанием и состоянием:

- **Установить плагин…** — выберите файл `plugin.toml` плагина; его папка копируется в `plugins/<id>` рядом с настройками. Повторная установка того же плагина обновляет его.
- **Удалить плагин** убирает его, **Включить или выключить плагин** оставляет установленным, но не загружает.
- **Перезагрузить плагины** загружает плагины заново, не перезапуская Birchpad.

У каждого плагина в меню **Плагины** своё подменю с его командами. Команды плагинов можно назначить на клавиши и записывать в макросы.

:::note[Безопасность]
Плагин и скрипт работают только с открытым документом: читают и правят текст, выделения, запускают команды Birchpad, показывают сообщения и свою панель. Доступа к файлам и сети у них нет. Плагин, который работает дольше нескольких секунд или берёт больше 256 МиБ памяти, останавливается.
:::

Администратор может разрешить только некоторые плагины или запретить их совсем — политиками `PluginInstall` и `AllowedPlugins`, а скрипты — политикой `UserScripts`. См. [Для администраторов](/docs/admin/).

## Скрипты на Rhai

Сохраните файл `.rhai` в папку `scripts` рядом с настройками (**Плагины → Скрипты → Открыть папку скриптов**) — он появится в меню **Плагины → Скрипты**. Скрипт работает с активным документом, а все его правки — один шаг отмены.

Пример — `title-case.rhai`, «Каждое Слово С Заглавной» для выделения:

```rust title="title-case.rhai"
let words = selected_text().split(" ");
let out = [];
for word in words {
    if word.len() > 0 {
        out.push(word.sub_string(0, 1).to_upper() + word.sub_string(1).to_lower());
    }
}
insert(out.reduce(|sum, w| if sum == () { w } else { sum + " " + w }));
```

| Функция | Что делает |
|---|---|
| `text()`, `set_text(s)` | весь текст |
| `length()` | его длина в байтах |
| `text_range(start, end)`, `replace(start, end, s)` | часть текста по смещениям в байтах |
| `selected_text()`, `insert(s)` | основное выделение; ввод поверх всех выделений |
| `selections()`, `set_selection(anchor, head)` | выделения как словари `#{anchor, head}` |
| `path()`, `language()` | файл документа (или `()`) и его язык |
| `run_command(id)`, `run_command(id, #{...})` | команда Birchpad — после завершения скрипта |
| `message(s)`, `print(s)` | сообщение |
| `show_panel(title, [lines])` | панель скриптов |

Идентификаторы команд — те же, что в `keymap.toml`, например `edit.select-all`. Скрипт останавливается после 50 миллионов операций.

## Свой плагин

Плагин — это папка:

```text
word-count/
├── plugin.toml
└── plugin.wasm
```

`plugin.toml`:

```toml
id = "word-count"            # строчные буквы, цифры и дефисы; это имя папки
name = "Word Count"          # подменю в меню «Плагины»
version = "1.0.0"
description = "Counts the words of the document."
author = "Jane Doe"
api = "0.1"                  # версия API плагинов
entry = "plugin.wasm"        # по умолчанию
events = ["saved"]           # opened, saved, closed, activated — что получает on-event
```

Компонент реализует мир `plugin` из [`crates/plugin/wit/birchpad.wit`](https://github.com/SecurityTrip/Birchpad/blob/main/crates/plugin/wit/birchpad.wit):

| Экспорт | Когда вызывается |
|---|---|
| `commands()` | один раз при загрузке: пункты меню `{ id, title }` |
| `run(command)` | при выборе пункта (по клавише или из макроса тоже) |
| `on-event(event)` | на события, перечисленные в `plugin.toml` |
| `on-panel-click(line)` | при щелчке по строке панели плагина |

Через интерфейс `host` плагин читает и правит документ (позиции — смещения в байтах UTF-8), ставит выделения, запускает команды Birchpad по идентификатору с аргументами в JSON, показывает сообщения и заполняет свою панель. Всё, что вызов сделал с документом, — один шаг отмены; вызов, завершившийся ошибкой, ничего не меняет.

### На Rust

С [`wit-bindgen`](https://crates.io/crates/wit-bindgen):

```rust
wit_bindgen::generate!({ path: "wit", world: "plugin" });

use birchpad::plugin::host;

struct WordCount;

impl Guest for WordCount {
    fn commands() -> Vec<Command> {
        vec![Command { id: "count".into(), title: "Count Words".into() }]
    }

    fn run(_command: String) -> Result<(), String> {
        let words = host::text().split_whitespace().count();
        host::message(&format!("{words} words"));
        Ok(())
    }

    fn on_event(_event: Event) {}

    fn on_panel_click(_line: u32) {}
}

export!(WordCount);
```

Соберите его для `wasm32-unknown-unknown` как `cdylib` и превратите в компонент с помощью [`wasm-tools`](https://crates.io/crates/wasm-tools):

```sh
cargo build --release --target wasm32-unknown-unknown
wasm-tools component new target/wasm32-unknown-unknown/release/word_count.wasm -o plugin.wasm
```

Плагин, который вызывает все функции API, лежит в репозитории: [`crates/plugin/tests/fixtures/probe`](https://github.com/SecurityTrip/Birchpad/tree/main/crates/plugin/tests/fixtures/probe).
