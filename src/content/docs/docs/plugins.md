Меню **Плагины** собирает встроенные аналоги популярных плагинов Notepad++, установленные плагины и ваши скрипты.

Плагины Notepad++ — это библиотеки DLL для Windows, и Birchpad их не загружает. Плагины Birchpad — компоненты WebAssembly: они работают на всех системах и запускаются в песочнице.

## Встроенные плагины

### JSON Viewer

**Форматировать JSON** раскладывает значения по строкам с отступами редактора, **Сжать JSON** убирает пробелы и переносы, **Сортировать ключи JSON** форматирует с ключами каждого объекта по порядку, **Проверить JSON** ищет ошибку и ставит на неё курсор. Всё работает с выделением или со всем документом; числа и строки остаются как написаны.

**Показать JSON Viewer** открывает рядом с документом дерево его JSON. Щелчок по узлу выделяет значение в тексте, **Найти путь JSON** (`$.store.book[0].title`) находит его по пути, а **Копировать значение**, **Копировать ключ** и **Копировать путь** копируют выбранное (при закрытой панели — то, что под курсором).

### XML Tools

- **Форматировать XML**, **XML в одну строку** и **Проверить синтаксис XML** — так же, как для JSON.
- **Вычислить выражение XPath…** показывает узлы, которые выбирает выражение.
- **Проверить сейчас** сверяет документ с его DTD или XML Schema (той, что он называет, или выбранной вами) и переходит к первой ошибке.
- **Экранировать выделенный текст** и **Снять экранирование выделенного текста**.
- **Автоматически закрывать теги** вставляет закрывающий тег при вводе открывающего.

### Hex Editor

**Показать в HEX** показывает байты документа вместо текста и правит их прямо там: две цифры на байт, поверх курсора или со вставкой (<kbd>Insert</kbd>), символы — в текстовой колонке, курсор общий с текстом. **Найти в HEX** ищет байты или текст в кавычках. Сколько байтов в строке, как их группировать и писать ли заглавными — в **Опции → Настройки… → Hex Editor**.

**Шестнадцатеричный дамп в новом документе** открывает байты строками по 16 в отдельном документе; после правки **Применить шестнадцатеричные данные к документу** возвращает их одним шагом отмены.

### Сравнение

Работает как ComparePlus: **Сравнение** ставит активный документ рядом с документом другого вида или предыдущей вкладкой. Пустые строки выравнивают общие строки обоих документов, внутри изменённых строк отмечено, что именно отличается, а различия видны на полосе прокрутки. Через мгновение после правки документы сравниваются заново.

- **Отличия от последнего сохранения**, **Сравнить с буфером обмена** и **Отличия от Git HEAD** сравнивают документ с его файлом, буфером обмена или последним коммитом Git.
- **Следующее различие** и **Предыдущее различие** переходят между ними, **Очистить результаты** снимает подсветку.
- Можно **игнорировать пробелы** и **регистр**; что включено — в **Опции → Настройки… → Сравнение**.
- Цвета задаются в теме: `compare-added`, `compare-removed`, `compare-changed`.

### Проверка орфографии

Работает как DSpellCheck в Notepad++:

- **Проверять орфографию автоматически** подчёркивает слова с ошибками;
- **Следующая ошибка** и **Предыдущая ошибка** переходят между ними;
- **Варианты исправления** показываются в списке автодополнения;
- **Добавить слово в словарь** и **Язык словаря**.

Английский (США) проверяется сразу: словарь, собранный из SCOWL, входит в Birchpad. Другие языки — **Скачать языки…** или файлы Hunspell `.aff` и `.dic` в папке `dictionaries` рядом с настройками (**Открыть папку словарей**), например из [репозитория словарей LibreOffice](https://github.com/LibreOffice/dictionaries).

В **Опции → Настройки… → Проверка орфографии** — несколько языков сразу, какие слова пропускать (с цифрами, заглавными буквами, с заглавной внутри или в начале, с подчёркиваниями, однобуквенные, адреса) и что проверять в коде: комментарии, строки, и то и другое или всё.

## Установка плагинов

**Плагины → Управление плагинами…** показывает установленные плагины и плагины из каталога Birchpad:

- **Обновить список** загружает каталог: оттуда ставятся новые плагины и обновляются установленные. Каждая загрузка проверяется по SHA-256 из каталога.
- **Установить…** — выберите файл `plugin.toml` плагина; его папка копируется в `plugins/<id>` рядом с настройками. **Опции → Импорт → Импортировать плагин(ы)…** ставит несколько сразу. Повторная установка обновляет плагин и сохраняет его настройки.
- **Разрешить файлы** даёт плагину, который об этом просит, читать, записывать и открывать файлы.
- **Удалить плагин** убирает его вместе с настройками и разрешением, **Включить или выключить плагин** оставляет установленным, но не загружает. **Перезагрузить плагины** загружает их заново без перезапуска Birchpad.

У каждого плагина в меню **Плагины** своё подменю с его командами, а некоторые добавляют пункты в контекстное меню текста. Команды плагинов можно назначить на клавиши (**Опции → Горячие клавиши… → Команды плагинов**) и записывать в макросы. Настройки плагинов — в **Опции → Настройки… → Плагины**.

Каталог и словари загружаются, только пока включены сетевые функции (`network.online-features`, политика `OnlineFeatures`).

:::note[Безопасность]
Плагин и скрипт работают с открытым документом: читают и правят текст и выделения, запускают команды Birchpad, показывают сообщения и свою панель. Плагин работает с файлами, только если вы разрешили это в управлении плагинами; к сети доступа нет ни у кого. Вызов, который длится дольше нескольких секунд или берёт больше 256 МиБ памяти, останавливается.
:::

Администратор может разрешить только некоторые плагины или запретить их совсем — политиками `PluginInstall` и `AllowedPlugins`, а скрипты — политикой `UserScripts`. См. [Для администраторов](/docs/admin/).

## Скрипты на Rhai

Сохраните файл `.rhai` в папку `scripts` рядом с настройками (**Плагины → Скрипты → Открыть папку скриптов**) — он появится в меню **Плагины → Скрипты**. Скрипт работает с активным документом, а все его правки — один шаг отмены.

Пример — `title-case.rhai`, «Каждое Слово С Заглавной» для выделения:

```rust title="title-case.rhai"
let words = selected_text().split(" ");
let out = [];
for word in words {
    if word.len() > 0 {
        out.push(word.sub_string(0, 1).to_upper() + word.sub_string(1).to_lower());
    }
}
insert(out.reduce(|sum, w| if sum == () { w } else { sum + " " + w }));
```

| Функция | Что делает |
|---|---|
| `text()`, `set_text(s)` | весь текст |
| `length()` | его длина в байтах |
| `text_range(start, end)`, `replace(start, end, s)` | часть текста по смещениям в байтах |
| `selected_text()`, `insert(s)` | основное выделение; ввод поверх всех выделений |
| `selections()`, `set_selection(anchor, head)` | выделения как словари `#{anchor, head}` |
| `path()`, `language()` | файл документа (или `()`) и его язык |
| `run_command(id)`, `run_command(id, #{...})` | команда Birchpad — после завершения скрипта |
| `message(s)`, `print(s)` | сообщение |
| `show_panel(title, [lines])` | панель скриптов |

Идентификаторы команд — те же, что в `keymap.toml`, например `edit.select-all`. Скрипт останавливается после 50 миллионов операций.

### Команды скрипта

Скрипт может объявить свои команды — по строке комментария на каждую: `// command: <функция> <название>`. Тогда в **Плагины → Скрипты** у него появляется подменю: **Выполнить** запускает скрипт целиком, а каждая команда — скрипт и затем свою функцию. Им тоже можно назначить клавиши.

```rust title="case.rhai"
// command: upper Upper Case
// command: lower Lower Case
fn upper() { insert(selected_text().to_upper()); }
fn lower() { insert(selected_text().to_lower()); }
```

Функции Rhai не видят переменных скрипта: общее для них выносите в функции.

## Свой плагин

Плагин — это папка:

```text
word-count/
├── plugin.toml
└── plugin.wasm
```

`plugin.toml`:

```toml
id = "word-count"            # строчные буквы, цифры и дефисы; это имя папки
name = "Word Count"          # подменю в меню «Плагины»
version = "1.0.0"
description = "Counts the words of the document."
author = "Jane Doe"
api = "0.2"                  # версия API плагинов
entry = "plugin.wasm"        # по умолчанию
events = ["saved"]           # что получают on-event и on-message
permissions = ["files"]      # просит разрешения работать с файлами

[[settings]]                 # видны в Опции → Настройки… → Плагины
key = "count-numbers"
title = "Count numbers as words"
kind = "bool"                # bool, number или text
default = "true"
```

`events`: `opened`, `saved`, `closed`, `activated`; `changed` (текст изменился — ввод, команда, отмена) и `selection-changed` (сдвинулся курсор или выделение) — оба приходят, когда изменение закончено; `message` — для `-pluginMessage` из командной строки.

Компонент реализует мир `plugin` из [`crates/plugin/wit/birchpad.wit`](https://github.com/SecurityTrip/Birchpad/blob/main/crates/plugin/wit/birchpad.wit):

| Экспорт | Когда вызывается |
|---|---|
| `commands()` | один раз при загрузке: пункты меню `{ id, title, context-menu }`; с `context-menu` они есть и в контекстном меню текста |
| `run(command)` | при выборе пункта (по клавише или из макроса тоже) |
| `on-event(event)` | на события из `plugin.toml`, с документом, которого они касаются |
| `on-panel-click(line)` | при щелчке по строке панели плагина |
| `on-control(id, value)` | при действии с элементом панели |
| `on-message(message)` | с `-pluginMessage`, если в `events` есть `message` |
| `run-task(task, input)` | в другом потоке, для задачи, которую запустил плагин; возвращает результат |
| `on-task-done(task, outcome)` | с результатом задачи, на активном документе |

Через интерфейс `host` плагин читает и правит документ (позиции — смещения в байтах UTF-8), ставит выделения, запускает команды Birchpad по идентификатору с аргументами в JSON, показывает сообщения и заполняет свою панель строками (`show-panel`) или элементами (`show-controls`: подписи, кнопки, текстовые поля, флажки, разделители). Всё, что вызов сделал с документом, — один шаг отмены; вызов, завершившийся ошибкой, ничего не меняет.

- **Настройки**: `setting(key)` и `set-setting(key, value)` хранят текст между запусками в `plugins/<id>.settings.toml`.
- **Файлы**: `read-file`, `write-file` и `open-file` с абсолютными путями — только с `permissions = ["files"]` и после **Разрешить файлы**.
- **Фоновая работа**: `start-task(task, input)` запускает `run-task` вне окна; результат приходит в `on-task-done`. Задача может работать в 12 раз дольше обычного вызова.

Плагины API 0.1 нужно пересобрать с новым `birchpad.wit` — всё, что было в 0.1, в нём осталось как было.

### На Rust

С [`wit-bindgen`](https://crates.io/crates/wit-bindgen):

```rust
wit_bindgen::generate!({ path: "wit", world: "plugin" });

use birchpad::plugin::host;

struct WordCount;

impl Guest for WordCount {
    fn commands() -> Vec<Command> {
        vec![Command {
            id: "count".into(),
            title: "Count Words".into(),
            context_menu: true,
        }]
    }

    fn run(_command: String) -> Result<(), String> {
        let words = host::text().split_whitespace().count();
        host::message(&format!("{words} words"));
        Ok(())
    }

    fn on_event(_event: Event) {}
    fn on_panel_click(_line: u32) {}
    fn on_control(_id: String, _value: String) {}
    fn on_message(_message: String) {}
    fn run_task(_task: String, _input: String) -> Result<String, String> {
        Err("no tasks".into())
    }
    fn on_task_done(_task: String, _outcome: Result<String, String>) {}
}

export!(WordCount);
```

Соберите его для `wasm32-unknown-unknown` как `cdylib` и превратите в компонент с помощью [`wasm-tools`](https://crates.io/crates/wasm-tools):

```sh
cargo build --release --target wasm32-unknown-unknown
wasm-tools component new target/wasm32-unknown-unknown/release/word_count.wasm -o plugin.wasm
```

Плагин, который вызывает все функции API, лежит в репозитории: [`crates/plugin/tests/fixtures/probe`](https://github.com/SecurityTrip/Birchpad/tree/main/crates/plugin/tests/fixtures/probe). Чтобы плагин попал в каталог, откройте pull request, который добавляет его в [`packaging/catalog/catalog.json`](https://github.com/SecurityTrip/Birchpad/blob/main/packaging/catalog/catalog.json) с адресом ZIP, размером и SHA-256. Подробнее — в [руководстве по плагинам и скриптам](https://github.com/SecurityTrip/Birchpad/blob/main/docs/plugins.ru.md).
