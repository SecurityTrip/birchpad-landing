## Пользовательские языки (UDL)

Birchpad читает UDL-файлы Notepad++ как есть. Положите их в папку `userDefineLangs` рядом с [настройками](/docs/settings/#где-лежат-файлы) или выберите **Синтаксис → Пользовательский синтаксис → Импорт…** — файл проверится и скопируется туда. В одном файле может быть несколько языков.

Языки появляются в меню **Синтаксис → Пользовательский синтаксис** и применяются к файлам с их расширениями, если расширение не занято встроенным языком. Выбранный язык сохраняется в сессии.

Подсвечиваются, как в Notepad++: блочные и строчные комментарии, разделители со своим escape-символом, операторы, числа, ключевые слова групп 1–8 (с учётом регистра или без, целиком или как префиксы). Цвета берутся из самого UDL-файла, а не из темы.

Пока нет редактора UDL, сворачивания по UDL, префиксов и суффиксов чисел и вложенных разделителей — они в [плане](/roadmap/).

## Автодополнение

Настройки — в **Опции → Настройки… → Автодополнение** и в разделе [`[completion]`](/docs/settings/#completion).

### Парные символы

Скобки и кавычки `()[]{}""''` закрываются при вводе. Ввод закрывающего символа перешагивает его, <kbd>Backspace</kbd> между пустой парой удаляет обе. Кавычка закрывается только там, где может начаться строка, — не после слова, где это апостроф. Работает для всех курсоров сразу. Набор пар задаёт `completion.auto-close`, например `"()[]{}«»"`.

### Список слов

При вводе слова показывается список: сначала ключевые слова и функции языка из API-файла с их сигнатурами, потом слова документа. <kbd>Ctrl</kbd>+<kbd>Space</kbd> вызывает его вручную. <kbd>↑</kbd> <kbd>↓</kbd> выбирают, <kbd>Enter</kbd> или <kbd>Tab</kbd> вставляют, <kbd>Esc</kbd> закрывает.

### Подсказки параметров

После открывающей скобки функции показываются её параметры — все перегрузки с описаниями. <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> показывает подсказку снова внутри вызова.

### API-файлы

Ключевые слова и функции берутся из API-файлов Notepad++: `autoCompletion/<язык>.xml` рядом с настройками, например `autoCompletion/python.xml`. Birchpad пока не поставляет их сам — возьмите файлы из папки `autoCompletion` Notepad++.
