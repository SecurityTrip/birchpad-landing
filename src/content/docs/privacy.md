title: Конфиденциальность

---

Birchpad не собирает персональные данные. В нём нет телеметрии, отчётов о сбоях и учётных записей. Документы, сессии и резервные копии остаются на вашем компьютере — в папке данных Birchpad или, в портативном режиме, в папке `data` рядом с программой.

## Сетевые запросы

Сам по себе Birchpad обращается к сети только ради обновлений:

- **Проверка обновлений** — раз в сутки, пока Birchpad запущен, и по команде **? → Проверить обновления…**. Скачивается манифест `https://github.com/SecurityTrip/Birchpad/releases/download/updates/birchpad-updates.json` или адрес из настройки `updates.url`. Запрос сообщает только версию Birchpad и операционную систему (заголовок `User-Agent`, например `Birchpad/0.1.4 (windows)`) — ничего о вас и ваших файлах.
- **Загрузка обновлений** — при `updates.mode = "auto"` (по умолчанию) копия, установленная установщиком для текущего пользователя на Windows, скачивает пакет новой версии по адресу из манифеста (загрузки релизов GitHub).
- **PlantUML** — только если вы нажмёте **Установить PlantUML** в [предпросмотре](/docs/preview/): PlantUML и Java для него скачиваются из релизов Birchpad на GitHub. При `network.online-features = false` эта кнопка не скачивает ничего.
- **Каталог плагинов и словари** — только когда вы сами нажмёте **Обновить список** в управлении плагинами или **Скачать языки…** в проверке орфографии: список скачивается из репозитория Birchpad на GitHub, а плагины и словари — по адресам из него, с проверкой по SHA-256. При `network.online-features = false` (политика `OnlineFeatures`) это выключено.

Эти файлы раздаёт GitHub и, как любой веб-сервер, видит запросы: адрес вашего компьютера или сети и время. На них распространяется [заявление о конфиденциальности GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

## Как отключить

- `updates.mode = "off"` в настройках Birchpad прекращает все сетевые запросы.
- `updates.mode = "notify"` проверяет и сообщает о новых версиях, но ничего не скачивает.
- Администратор может задать то же политикой `UpdateMode`, которую пользователь не переопределит. См. [Для администраторов](/docs/admin/).

Ссылки, которые вы открываете сами (например, «Открыть страницу загрузки» в уведомлении об обновлении), открываются в вашем браузере.
