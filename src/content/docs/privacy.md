Документы, сессии и резервные копии хранятся на вашем компьютере. У Birchpad нет учётных записей и отправки отчётов о сбоях. При проверке обновлений по умолчанию отправляется статистика установок. Её можно выключить в настройках.

## Сетевые запросы

- **Обновления.** Birchpad запрашивает подписанный манифест у `https://api.birchpad.ru/v1/updates/check`, а при сбое — у GitHub. Настройка `updates.url` направляет запросы на указанное зеркало, без статистики установок. При автообновлении установленные через Windows EXE и macOS PKG копии скачивают новую версию по адресу из манифеста.
- **PlantUML, плагины и словари.** Загрузка запускается по вашей команде. Её можно отключить через `network.online-features = false`. См. [Предпросмотр](/docs/preview/) и [Плагины и скрипты](/docs/plugins/).

Языковые серверы — программы, которые вы настраиваете сами. Birchpad запускает их на вашем компьютере и передаёт им текст документов соответствующего языка. Интеграция с Git читает данные из локального репозитория через установленный `git`.

GitHub получает сетевой адрес и время запроса при обращении к его файлам. На эти запросы распространяется [политика конфиденциальности GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).

## Статистика установок

Запрос передаёт случайный ID установки, версию Birchpad, канал обновлений, платформу, способ установки PlantUML и версию компонента Birchpad, если он установлен. ID создаётся при первой проверке с включённой статистикой и хранится в `state.toml`. Он не связан с данными компьютера или пользователя.

Сервис хранит одну запись на ID: первую и текущую версии, канал, платформу, сведения о PlantUML и время первой и последней проверки. IP-адреса, заголовки User-Agent и история проверок не сохраняются.

## Как отключить

- `updates.statistics = false` отключает статистику и удаляет ID из `state.toml`. Проверка обновлений отправляет пустое тело `{}`.
- `updates.mode = "off"` отключает проверку и загрузку обновлений. Чтобы также отключить загрузку PlantUML, плагинов и словарей из каталога, задайте `network.online-features = false`.
- `updates.mode = "notify"` оставляет уведомления о новых версиях без автоматического скачивания.
- Администратор может задать политики `UpdateStatistics`, `UpdateMode` и `OnlineFeatures`. См. [Для администраторов](/docs/admin/).

Ссылки, которые вы открываете сами, переходят в браузер.
