Сначала Birchpad догоняет Notepad++ (этапы 1–6), потом идёт дальше (этап 7). Этапы упорядочены по зависимостям, а не по календарю. Подробный список с отметками — в [ROADMAP.md](https://github.com/SecurityTrip/Birchpad/blob/main/docs/ROADMAP.md).

## ✓ 1. Первый блокнот

Вкладки, кодировки и концы строк без потерь, простой поиск и замена, строка состояния как в Notepad++, один экземпляр с командной строкой Notepad++, установщики, портативный режим.

## ✓ 2. Редактор уровня Notepad++

Подсветка 50 языков на tree-sitter, вложенные языки, сворачивание, мультикурсор и столбцы, умная подсветка, закладки, операции со строками, два вида, сессии с резервными копиями, слежение за файлами, автообновления.

## ✓ 3. Поиск и навигация — 0.1.3

Расширенный режим и регулярные выражения, пометки, поиск в файлах, панель результатов, пошаговый поиск, боковые панели (список функций, карта документа, рабочее пространство, проекты), история переходов, история изменений.

## ✓ 4. Настройка — 0.1.4

Темы и импорт тем Notepad++, «Определение стилей», окно настроек, редактор горячих клавиш, макросы, пользовательские языки, автодополнение, меню «Запуск» и «Инструменты», кодовые страницы DOS и EBCDIC, русский интерфейс, печать, текст справа налево.

## ✓ 5. Плагины — 0.1.5

Плагины как компоненты WebAssembly в песочнице (команды, события документов, панель плагина), скрипты на Rhai, управление плагинами со списком разрешённых для организаций и политикой `UserScripts`. Встроенные версии популярных плагинов Notepad++: JSON Viewer, XML Tools, Hex Editor, Сравнение, Проверка орфографии. Весь интерфейс переведён на русский.

## ✓ 6. Полный паритет с Notepad++ — 0.2.0 → 0.6.0

Всё, что этапы 1–5 сделали иначе или оставили на потом. Этап выходит несколькими релизами:

- **✓ 0.2.0** — закреплённые и цветные вкладки, меню вкладки и «Закрыть несколько документов», переключатель документов, меню «Окна», панель инструментов, контекстное меню текста, режимы окна, тёмный интерфейс, шрифты в темах, новые разделы настроек, «Edit with Birchpad» в Проводнике, Birchpad как редактор по умолчанию.
- **✓ 0.3.0** — обновление из окна с новостью о нём, тесты: в четыре раза быстрее и намного шире.
- **✓ 0.4.0** — предпросмотр Markdown и PlantUML, редактор UDL, свои API-файлы для 15 языков, закрытие тегов HTML и XML, текст справа налево, немецкий интерфейс, EBCDIC 875 и NEL.
- **✓ 0.5.0** — печать с предпросмотром, хэши файлов в окне, меню «?» как в Notepad++, все ключи командной строки Notepad++, установка PlantUML одной кнопкой.
- **✓ 0.6.0** — API плагинов 0.2 (настройки, файлы с разрешения, свои панели, фоновая работа), команды скриптов, сравнение как в ComparePlus, дерево JSON Viewer, XPath и проверка по схеме в XML Tools, Hex Editor в документе, английский словарь в комплекте, онлайн-каталог плагинов, документация на русском, последняя сверка с Notepad++.

## 7. Дальше Notepad++ — 0.7.0 → 1.0.0

- **0.7.0** — палитра команд, быстрый поиск файлов, синтаксическое выделение, закреплённые заголовки областей и то немногое из меню, настроек и командной строки Notepad++ 8, что нашла последняя сверка.
- **0.8.0** — клиент LSP, Git (изменения на полях, blame, diff), встроенный терминал.
- **0.9.0** — файлы в несколько гигабайт, просмотр CSV и JSON, правка по SSH/SFTP, режим Vim.
- **1.0.0** — закрытие этапа.

## Выпуск

| Канал | Из чего | Как часто |
|---|---|---|
| Nightly | ветка следующей версии | каждую ночь, если есть изменения |
| Beta | `release/x.y` | раз в 1–2 недели |
| Stable | теги ветки релиза | раз в 4–8 недель |

Готовятся: подпись Authenticode для Windows и нотаризация для macOS, MSI для ARM64, манифесты winget и Scoop, шаблоны ADMX/ADML.
