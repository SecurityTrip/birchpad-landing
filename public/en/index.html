Features

Everything you open Notepad++ for

The project's first goal is feature parity with Notepad++. All the everyday work is already there, from regular expressions to themes, macros and plugins.

Tabs as in Notepad++

Pin and color tabs, switch with Ctrl+Tab in the order you used them. Drag a tab to the right or the bottom and the document opens in the second view.

50 languages

Highlighting and folding with tree-sitter, in the background and without stutter. It understands nesting: scripts in HTML, code in Markdown, regexes in JavaScript.

Multi-cursor and columns

Edit dozens of lines in one go, select a rectangle, and paste columns.

Encodings without mojibake

UTF-8 with and without BOM, UTF-16, legacy code pages such as Windows-1252. “Encode in” and “Convert to” work as in Notepad++, and saving is lossless.

Sessions that never lose work

Close the editor with unsaved drafts and they are back on the next start, along with your tabs.

Change history

A margin marks the lines you changed: orange until they are saved, green after.

Search the way you're used to

Normal, Extended (\n, \t, \x41) and regular expressions with back-references. Find in Files with Notepad++'s filters, marks, bookmarks, incremental search and a results panel.

Find what:  fn (\w+)\(
Replace:    pub fn $1(
Filters:    *.rs *.toml !\target
Directory:  ~/projects
— 214 hits in 37 files

Panels

Function List for 28 languages, Document Map, Folder as Workspace, projects, Clipboard History and the Character Panel.

Themes and settings

Light and dark themes, Notepad++ XML themes as they are, the Style Configurator, Preferences and the Shortcut Mapper — every change applies at once.

Macros and Run

Record and replay to the end of the file, the Run menu with $(FULL_CURRENT_PATH) variables, MD5 to SHA-512 hashes, Base64, URL and HEX.

Your languages, completion

Notepad++ User Defined Languages and an editor for them, API files for 15 languages, closing brackets, quotes and HTML tags, and call tips that go through overloads.

Plugins

Built-in versions of popular Notepad++ plugins: JSON Viewer with its tree, XML Tools with XPath and schema validation, Hex Editor in the document itself, ComparePlus-style Compare and a Spell Checker. Write your own plugins in any language as WebAssembly, or short scripts in Rhai; Plugins Admin has a catalog. A plugin uses files only once you allow it, and never the network.

// scripts/shout.rhai
let s = selected_text();
insert(s.to_upper());
let n = s.split(" ").len();
message(`Words: ${n}`);

English, Russian, German

Menus, dialogs, messages and the status bar in English, Russian or German, following the system's language or the one you choose. A Notepad++ translation file names the menus in any other language.

Your default editor

“Edit with Birchpad” in the Windows Explorer’s context menu, and Birchpad as the default app for .txt, .json, .xml, .md and .log files.

A window for the task

Notepad++’s toolbar, the Window menu, Always on Top, full screen, Post-It and Distraction Free Mode. A dark interface with any theme.

The right click

The text’s context menu is configurable, like Notepad++’s contextMenu.xml. Open the file a selection names, search the web for it, open links with Ctrl+click.

Markdown and PlantUML preview

A Markdown document shows its text and the rendered page side by side, as in IntelliJ IDEA; the buttons in the corner show the text, both, or the page alone. PlantUML diagrams in .puml files draw the same way, and Birchpad installs PlantUML and its Java for you with one button.

// login.puml
@startuml
Browser -> Server: POST /login
Server --> Browser: 200 OK
@enduml

Print preview

The pages as they will come out of the printer: margins, headers and footers with Notepad++’s variables, line numbers, color modes. On Windows, the system’s print dialog and Print Now.

Switching

From Notepad++, without relearning

Birchpad keeps what your fingers and scripts already know, and runs on more than Windows.

What stays the same

  • Shortcuts and menus. Ctrl+Shift+F, Ctrl+M, F3 and the rest are where you expect them.
  • The command line. -n, -c, -l, -ro, -multiInst: file associations and scripts keep working.
  • Notepad++'s files. .workspace projects, session.xml sessions, XML themes, User Defined Languages and auto-completion API files open as they are.
  • A single instance. Launching again opens the files as tabs in the running window.

What you gain

  • macOS and Linux. One editor on all your machines, with the same settings.
  • A native GPU-drawn UI. No Electron, no Chromium inside.
  • Safe plugins. Plugins and scripts run in a sandbox, without files or the network, with time and memory limits.
  • Safe updates. An ed25519-signed manifest, and an SBOM and GitHub build provenance with every release.
  • Portable mode. Unzip it to a USB stick and the settings stay next to the program.
> birchpad -n120 -lpython script.py
> birchpad -ro -multiInst C:\logs\today.log
0 requests

Sends nothing

No telemetry, no crash reports, no accounts. Your files, sessions and backups stay on your computer. Birchpad goes online only to check for updates, once a day, and with updates.mode = "off" it makes no network requests at all. Privacy policy

MSI

Ready for organizations

A per-machine MSI, administrator policies in the Windows registry that users cannot override: update channels, a plugin allowlist, turning scripts off. For administrators. Every release is built on GitHub's runners from the open source, with SHA-256 checksums.

Why “Birchpad”

A notepad made of birch bark

Before paper became common in medieval Novgorod, people wrote everyday notes, letters and school exercises on strips of birch bark. A boy named Onfim practised his alphabet on them and drew himself as a rider; merchants settled debts; neighbours sent their greetings.

Birch-bark letters were the notepads of their time, and Birchpad is named after them.

Questions

Frequently asked

Is it a fork of Notepad++?

No. Birchpad is written from scratch in Rust and is not affiliated with Notepad++. It follows its features and habits so that switching is painless, but the code is its own and it runs on three systems.

How ready is it?

It is a beta: everything people usually open Notepad++ for is there, from Find in Files to themes, macros and plugins. Since 0.6.0 Birchpad does what matters in Notepad++, and what comes next is what Notepad++ does not have: a command palette, LSP, Git. Report bugs and ideas in GitHub Issues.

Do Notepad++ plugins work?

Notepad++ plugins are Windows DLLs, and Birchpad does not load them. Instead it has its own versions of the most popular ones: JSON Viewer, XML Tools, Hex Editor, Compare and Spell Checker. New plugins are written in any language as WebAssembly and run on all three systems — see Plugins and scripts.

Is there Notepad++ for macOS and Linux?

Notepad++ runs only on Windows. Birchpad follows its features, menus and keyboard shortcuts and runs on Windows, macOS and Linux, with the same settings, themes and macros everywhere. Notepad++ themes, user defined languages, sessions and projects open as they are — see Switching from Notepad++.

Why does Windows warn me on the first start?

Windows builds are not signed with a certificate yet: signing through SignPath is ready and will be switched on once the project has a certificate. Until then, SHA-256 checksums and GitHub build provenance show that a file is what the release workflow built.

How can I help?

Star the project on GitHub, tell your colleagues, report bugs. Code is welcome through pull requests — start with the contributing guide.
